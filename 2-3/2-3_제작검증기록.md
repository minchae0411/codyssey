## 수정 기록

### 수정 기록 1
- 발견한 문제: 메모를 쓰기위해 0.5초간 누를때 로딩바가 있었으면 좋겠다고 생각함
- AI에게 전달한 요청: 메모 핀을 만들기 위해 1초간 누르고 있을 때 원형 로딩바가 돌아가면서 메모창이 켜질때 까지의 남은 정도를 보여줬으면 좋겠어
- 수정 후 테스트 결과: 원형 로딩바가 생겨 남은 시간을 사용자가 파악할 수 있게됨
- 수정 이유: 기존엔 선택 지점에서 원 모양으로 퍼져나가는 식으로 구현 되어 메모창이 켜질 때까지의 남은 정도를 알지 못했기 때문에 로딩바를 구현함.

### 수정 기록 2
- 발견한 문제: 이미지 비율이 기본 화면 규격에 맞춰지거나, 브라우저 크기를 줄이면 이미지가 잘림
- AI에게 전달한 요청: 저장한 이미지 규격에 맞춰 사진을 불러오도록 해주고 브라우저 크기를 줄여도 사진이 잘리지 않도록 해줘
- 수정 후 테스트 결과: 이미지 비율을 바꾸지 않고 가져올 수 있고, 브라우저 크기와 상관없이 이미지를 볼 수 있음.
- 수정 이유: 이미지 비율을 그대로 불러오고 싶었고 브라우저 크기를 줄여도 이미지를 온전히 볼 수 있으면 좋겠다 생각함

### 수정 기록 3
- 발견한 문제: 선명도가 진해서 글자가 가려지는 상황이 생김.
- AI에게 전달한 요청: 그림 도구의 선명도를 조절할 수 있도록 해줘
- 수정 후 테스트 결과: 네 종류의 그림 도구의 선명도 조절 가능
- 수정 이유: 선명도를 조절할 수 있다면 사용자의 메모 기능 활용도가 높아질 것이라 생각함

### 수정 기록 4
- 발견한 문제: 생성된 핀과 핀에 커서를 올릴 때 메모의 내용이 길게 보여서 이미지를 가림
- AI에게 전달한 요청: 메모를 쓰고 생성되는 핀이 사진을 가려서 불편해. 핀의 크기를 펜 두께 1로 점 찍은 크기로 만들어주고, 마우스 커서를 핀에 올려뒀을 땐 전체 내용이 아닌 메모 내용을 요약해서 보여줘
- 수정 후 테스트 결과: 핀이 점 크기로 작게 바뀌었고, 마우스 커서를 올리면 메모 내용을 요약해줌
- 수정 이유: 핀과 메모 내용이 길게 보여 이미지를 가림
